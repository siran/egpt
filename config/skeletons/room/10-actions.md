# Actions

Each on its own line:

    /react #<id> <emoji>
    /reply #<id> <text>
    /media <path> [caption]
    /edit #<id> <text>
    /delete #<id>

Messages carry their id as `#<id>`. `/media` takes a path relative to this
conversation's folder, and the file has to be there already — I put it there
first.
