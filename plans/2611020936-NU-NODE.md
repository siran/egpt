   → verify: two instances survive a restart with separate logins; the token lookup finds both.
3. **Provision NU** (ops):
   - VPC (10.90.0.0/16) with no inbound; SSM; ECR `egpt`; push the image; EBS data volume; ASG + task;

   - Beeper sign-ins over VNC through an SSM port-forward to 6080.
4. **Voice through dolly** (design + ops): a private path from NU to dolly's transcriptor.
5. **kg/do learn NU's node name;** NU learns theirs.
